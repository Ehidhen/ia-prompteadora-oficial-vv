# IA Prompteadora Oficial VV

Repositorio oficial para compartir y colaborar en prompts e ideas de IA.

## ¿Qué es esto?

Aquí se suben prompts, recursos y actualizaciones. Cualquier colaborador con acceso
puede subir cambios, y todos pueden descargar las últimas actualizaciones.

## Cómo colaborar

### 1. Clonar el repositorio
```bash
git clone https://github.com/Ehidhen/ia-prompteadora-oficial-vv.git
cd ia-prompteadora-oficial-vv
```

### 2. Subir cambios
```bash
git add .
git commit -m "Describe tu cambio aquí"
git push
```

### 3. Bajar las últimas actualizaciones
```bash
git pull
```

## Estructura

- `prompts/` — Prompts organizados por tema.
- `recursos/` — Material de apoyo.
