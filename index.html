Cómo usar el repositorio

  1. Clona el repo: git clone https://github.com/Ehidhen/ia-prompteadora-oficial-vv.git
  2. Agrega tus prompts o recursos en las carpetas correspondientes.
  3. Sube tus cambios: git add . → git commit -m "mensaje" → git push
  4. Desde otra computadora, baja lo último con git pull
